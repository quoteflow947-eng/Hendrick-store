# Hendrick Store

Premium minimalist electronics & gadgets e-commerce store.
Built with Python + Flask + HTML + CSS + JavaScript + SQLite.

## Run locally

python -m venv venv

Windows:
venv\Scripts\activate

macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
python app.py

Open http://127.0.0.1:5000

## Create the database (ready for Step 2)

python database.py
